## 用混元 3 做数据分析

我相信大部分小伙伴在工作中都会遇到一个场景：拿着一堆 Excel 报表，看半天看不出个所以然，手动做可视化又要忙上很久。

这时候 WorkBuddy 就能派上大用处。它内置了一个 `xlsx` Skill，专门处理创建表格、编辑表格和数据分析等需求。

![WorkBuddy 内置的 xlsx Skill](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_005.png)

开启任务时，在输入框里唤起它即可使用。

举个例子。我现在有一份包含很多 Sheet 的报表，多到让人看一眼就头大，根本不想再看第二眼。

![包含大量 Sheet 的 Excel 报表](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_006.png)

别说这么多 Sheet，光是看这一张两年的数据报表，自己动手分析和制作可视化就得花上很久。

![需要分析的两年数据报表](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_007.png)

但我们可以直接交给 WorkBuddy 的 `xlsx` Skill 来完成。

![在输入框中唤起 xlsx Skill](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_008.png)

在输入框里输入 `/xlsx`，选择弹出的内置 Skill，然后描述自己的需求。

![选择混元 3 执行表格分析](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_009.png)

模型可以选择最新的混元 3 来完成任务，而且目前在 WorkBuddy 里可以免费使用。

接下来就可以看 WorkBuddy 工作了。

![WorkBuddy 分析 Excel 报表](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_010.png)

没等多久，它就完成了分析，还提供了六个关键发现，既指出表现好的地方，也标出了需要关注的问题。

最重要的数据可视化工作，WorkBuddy 不仅在原始 Excel 里完成了，还单独生成了一份汇总展示图表，这一点确实出乎我的意料。

![WorkBuddy 生成的数据汇总图表](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_011.png)

它还把分析内容直接写进了 Excel。

![Excel 中的分析结论](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_012.png)

如果 Excel 熟练度一般，自己对着这张表做出几张图，再配上分析，怎么也得花上大半天。

还有一个很妙的地方：就算表里的 Sheet 再复杂，也可以直接让它找出异常点。

![让 WorkBuddy 查找表格异常点](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_013.png)

如果觉得这些分析仍然过于表面，WorkBuddy 还有更专业的办法。在专家列表里搜索数据分析相关专家。

![搜索数据分析专家](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_014.png)

可以看到 WorkBuddy 早就准备好了对应的专家团。这里直接选择数据分析专家，点击召唤。

![召唤数据分析专家团](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_015.png)

模型同样选择混元 3，就可以开始看数据分析专家团工作了。

![混元 3 主动向用户征求意见](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_016.png)

遇到不确定的问题时，混元 3 会主动调用问询工具征求意见，确保方向不会出错。等待一会儿，就能看到专业专家团给出的结果。

![数据分析专家团输出结果](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_017.png)

它一共输出了三种关键文件格式：PPTX、XLSX 和 HTML。要不怎么说，专家团干活就是比一个人效率高。

![专家团生成的 PPT 汇报材料](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_018.png)

我看了一下 PPT 的质量，基本已经到了可以直接拿去汇报的程度。如果还缺一份 PDF 报告，让它再生成一份即可。

![数据分析专家团的完整交付文件](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_019.png)

## 用 WorkBuddy 制作视频

对，你没看错。甚至可以在 WorkBuddy 里制作视频，而且不需要 Seedance 这样的视频生成模型，直接使用混元 3 就行。

它背后的原理是使用 Remotion 这类基于 React 的动画框架。当然，不懂这些也没有关系，因为 WorkBuddy 已经直接安装了一个视频生成专家。

![WorkBuddy 中的视频生成专家](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_020.png)

使用时直接召唤它即可。

举个例子。我之前做了一个自己的提示词网站，叫 Aestara。

![Aestara 提示词网站](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_021.png)

但这个网站一直缺少推广介绍视频。再加上我是一个顶级 I 人，宁愿憋死，也不愿意专门出镜介绍它。这时就可以用到视频生成专家。

![让视频生成专家制作网站介绍视频](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_022.png)

最简单的办法，就是把链接交给它，再说明自己的需求。它会先询问想要什么尺寸的视频。

![视频生成专家询问画面尺寸](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_023.png)

然后它会自己安装依赖、配置环境，并设计拍摄脚本。

![WorkBuddy 设计视频脚本并配置环境](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_024.png)

## 用专家团处理产品需求

我相信很多产品经理经常会面临一种情况：老板丢过来一个竞品链接，说我们照着它的功能做一下，再升级一下。

一般遇到这样的老板或甲方，已经让人忍不住想开始问候他家里人了。

![产品经理面对临时需求的表情包](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_028.jpeg)

但我最近发现，WorkBuddy 上有一个产品战略专家团，用来拆需求、写 PRD 和做调研非常不错。

![WorkBuddy 产品战略专家团](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_029.png)

我仍然用自己的提示词网站作为例子。因为研究对象是网站，还需要一个叫 `agent-browser` 的插件，帮助 Agent 在访问网页时进行交互和截图。

![WorkBuddy 内置的 agent-browser 插件](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_030.png)

不用担心，这个插件同样是 WorkBuddy 内置的。配合 `agent-browser` Skill，就可以对竞品进行全方位研究。

![让产品战略专家团研究竞品网站](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_031.png)

这个产品战略专家团中一共有六个角色，各司其职，会从不同角度完成任务。

![产品战略专家团的六个角色](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_032.png)

最后它输出了两个文档：一个是 Aestara 的 PRD，可以直接拿来查看；另一个是竞品分析师生成的竞品分析报告。

![产品战略专家团生成的 PRD 与竞品报告](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_033.gif)

两个文档我简单扫了一遍，基本都是万字长文级别的完成度。放到团队里，产品同学手工完成三天都不一定能做到这个程度。

而且内容确实很细致，特别是这种流程图，一看就是老产品人的手法。

![PRD 中的产品流程图](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_034.png)

产品功能对比矩阵也能看出，它确实做过深度搜索。

![竞品功能对比矩阵](/media/workbuddy-tutorials/workbuddy-hunyuan3-workflow-guide/img_035.png)

内容非常详细。即使后期校验时发现少量错误，修改起来也很容易，因为完整的框架和基础已经搭建好了。

## WorkBuddy 的真正价值

我身边有很多朋友，并不像我一样对 AI 天然好奇，甚至有点上头。

他们不会每天追着模型发布会看，不会关心参数、架构和 Benchmark，也不会因为某个模型开源，就大半夜坐起来研究。

他们更关心一个很现实的问题：这个东西到底能不能帮我把活干完？能不能让我少加一点班、少熬一点夜，少在一堆 Excel、PPT、文档和需求里反复横跳？

能不能用尽可能低的成本，在保证质量的情况下，把那些原本需要花费大量时间、耐心和沟通成本的工作，变得轻松一些？

所以我越来越觉得，AI 真正进入普通人工作流的方式，可能不是所有人都去写代码，也不是每个人都变成所谓的超级个体。

写代码当然很重要，但它终究还是一个相对垂直、服务于一部分人的场景。而真正更大的场景，是工作本身。

是数据分析，是汇报材料，是产品需求，是竞品调研，是视频推广，是那些每天都在发生，却又让人非常痛苦的重复性工作。

我相信 AI 最有价值的地方，不是把我们变成超级天才，而是让普通人从繁琐、低效、重复的工作里，多拿回一点属于自己的时间。

这也是 WorkBuddy 的真正价值。它没有让工作消失，但确实让工作没那么折磨了。
