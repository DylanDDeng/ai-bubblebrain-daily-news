## Codex 进入 ChatGPT 移动端

终于等到 OpenAI 给 Codex 加上移动端了。广大网友的强烈呼声还是被 OpenAI 听到了。

![OpenAI 宣布 Codex 接入 ChatGPT 移动端](/media/codex-tutorials/codex-mobile-chatgpt-guide/img_001.png)

这次 OpenAI 没有专门为 Codex 再做一个手机 App，而是把它整合进了 ChatGPT，也比较符合 OpenAI 想做超级 App 的思路。

## 将手机与 Mac 配对

配对方法很简单：

1. 先把电脑上的 Codex App 升级到最新版。
2. 重新打开 Codex App，按照引导开始连接手机与 Mac。

![Codex App 的手机配对引导](/media/codex-tutorials/codex-mobile-chatgpt-guide/img_002.png)

点击开始后，电脑上会显示配对二维码。

![Codex App 显示的手机配对二维码](/media/codex-tutorials/codex-mobile-chatgpt-guide/img_003.png)

打开手机相机扫描二维码，页面会跳转到 ChatGPT App。

![ChatGPT App 请求连接 Codex](/media/codex-tutorials/codex-mobile-chatgpt-guide/img_004.jpeg)

![在 ChatGPT App 中授权访问 Codex](/media/codex-tutorials/codex-mobile-chatgpt-guide/img_005.jpeg)

一路完成授权后，就能在手机上看到原本在电脑里与 Codex 的对话消息。

![手机端同步显示 Codex 对话](/media/codex-tutorials/codex-mobile-chatgpt-guide/img_006.jpeg)

一个词总结这个配对过程：非常丝滑。

## 移动端使用体验

完成配对后，就可以直接在手机上启动 Coding 任务。我简单试了一下，整体体验和在电脑上没有太大区别。

![在手机端使用 Codex 执行编程任务](/media/codex-tutorials/codex-mobile-chatgpt-guide/img_007.jpeg)

整体功能已经比较完善。以后无论是在通勤途中，还是临时离开电脑，都可以继续查看和推进任务。

## 一个显示问题

测试过程中还发现一个比较有意思的小问题：Context Window 的显示出现了明显错位。

![Codex 手机端 Context Window 显示错位](/media/codex-tutorials/codex-mobile-chatgpt-guide/img_008.jpeg)

果然用 Codex 写前端还是会偶尔翻车，但凡是人写的代码，都很难写出这么离谱的 Bug。
